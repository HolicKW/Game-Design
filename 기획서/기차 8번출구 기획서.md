## 2. 핵심 컨셉

### 2.1 두 가지 축의 결합

```
[탑승구 역무원 시뮬레이션]  ×  [이상현상 탐지]
 ├─ 탑승권 확인·개찰      ├─ 미묘한 환경 변화
 ├─ 승객 안내·탑승 유도    ├─ 반복되는 공간 구조
 ├─ 열차 도착/출발 관리    ├─ 존재하지 않는 열차
 └─ 플랫폼 안전 관리      └─ 비정상적 승객 행동
```

- **표면**: 플레이어는 KTX 탑승구의 역무원으로서 주간~야간 근무를 수행한다
- **이면**: 평범한 주간 근무가 지나고 야간이 되면서 탑승구 주변에서 현실이 어긋나기 시작하며, 이상현상을 발견하고 올바르게 대응해야 한다

### 2.2 주간 → 야간 전환의 핵심

> 주간 근무는 **"정상"을 학습하는 시간**이다.
> 플레이어가 탑승구의 구조, 승객 패턴, 열차 시간표를 익힌 뒤,
> 야간에 들어서며 "무엇이 달라졌는지"를 스스로 감지해야 한다.

- ☀️ **주간** — 밝고 활기찬 분위기. 업무 튜토리얼 + 정상 상태 기억 유도
- 🌅 **석양** — 승객이 줄고 조명이 바뀌며 불안한 기류가 감지됨
- 🌙 **야간** — 이상현상 본격 시작. 같은 탑승구가 전혀 다른 공간처럼 느껴짐

### 2.3 핵심 감정 경험

> 😰 *"낮에는 분명 저 광고판이 이 자리에 없었는데...?"*\
> 😱 *"이 열차는 시간표에 없는데 왜 탑승구에 들어오는 거지?"*\
> 😨 *"저 승객, 아까 개찰구에서 확인했는데 또 나타났어...?"*

## 3. 게임 플레이 구조

### 3.1 핵심 컨셉: 열차 정차 = 이상현상 라운드

> **열차가 탑승구에 정차할 때마다, 탑승구 주변에 이상현상이 발생한다.**
> 플레이어는 열차가 정차해 있는 동안 업무를 수행하면서 이상현상을 찾아내고 해결해야 한다.
> 열차가 출발하면 라운드 종료 — 하루에 **3~4회 정차**가 한 사이클이다.

### 3.4 하루 진행 조건

| 항목 | 내용 |
|------|------|
| **정차 횟수** | 하루 **3~4회** (날짜·난이도에 따라 변동) |
| **라운드당 이상현상** | 1~3개 (라운드가 진행될수록 증가) |
| **통과 조건** | 하루 동안 발생한 이상현상의 **일정 비율 이상 해결** 시 다음 날로 진행 |

## 4. 탑승구 역무원 업무 시스템

### 4.1 주요 업무 목록

| 업무 | 설명 | 이상현상 연결 |
|------|------|---------------|
| **탑승권 확인·개찰** | 승객의 KTX 탑승권을 스캠하고 탑승 허가 | 없는 열차의 탑승권을 가진 승객, 만료된 탑승권 |
| **승객 안내·탑승 유도** | 플랫폼 번호·탑승 위치 안내 | 존재하지 않는 역을 물어보는 승객 |
| **열차 도착/출발 관리** | 시간표 확인, 도착·출발 신호 | 시간표에 없는 열차 도착, 목적지 변경 |
| **안내 방송** | 도착/출발/지연 안내방송 송출 | 방송 내용이 혼자 바뀌는 현상 |
| **플랫폼 안전 가드** | 안전선 및 승객 안전 관리 | 안전선 너머에 서 있는 승객, 선로 쪽으로 걸어가는 사람 |
| **순찰** | 탑승구 주변 정기 점검 | 순찰 경로 변화, 없던 공간 등장 |

### 4.2 역무원 도구

- **탑승권 스캠너** — 승객 탑승권 유효성 확인 (이상현상: 존재하지 않는 역/열차 표시)
- **무전기** — 관제센터와 교신 (이상현상 시 응답이 이상해짐)
- **시간표 태블릿** — 열차 정보 확인 (내용이 실시간으로 변하는 현상)
- **손전등** — 야간 어두운 구역 탐색
- **역무 일지** — 이상현상 기록 (기록 내용이 변하는 현상)

## 5. 이상현상 시스템

### 5.1 이상현상 분류

#### 🟢 Tier 1 — 미세 변화 (쉬움)
> 관찰력을 시험하는 레벨. 놓쳐도 즉각적 페널티 없음.

| # | 이상현상 | 정상 상태 |
|---|---------|-----------|
| 1 | 역 시계가 거꾸로 돌아감 | 정상 시계 방향 |
| 2 | 광고판 문구가 미묘하게 변경 | 원래 문구 |
| 3 | 자판기 음료 종류가 바뀜 | 원래 라인업 |
| 4 | 벤치 위치가 미세하게 이동 | 원래 위치 |
| 5 | 안내 표지판의 화살표 방향이 반대 | 정상 방향 |

#### 🟡 Tier 2 — 공간/시간 왜곡 (보통)
> 공간 구조와 시간이 어긋나기 시작.

| # | 이상현상 | 정상 상태 |
|---|---------|-----------|
| 1 | 복도 끝이 막다른 벽으로 변함 | 통로 연결 |
| 2 | 화장실 거울에 다른 모습 반사 | 정상 반사 |
| 3 | 계단을 내려갔는데 같은 층 도착 | 아래층 도착 |
| 4 | 시계가 갑자기 2시간 점프 | 정상 흐름 |
| 5 | 플랫폼 번호가 존재하지 않는 숫자 | 1~8번 |

#### 🔴 Tier 3 — 존재 이상 (어려움)
> 직접적으로 위협적인 이상현상. 즉각 대응 필요.

| # | 이상현상 | 정상 상태 |
|---|---------|-----------|
| 1 | 시간표에 없는 열차가 도착 (탑승 금지) | 시간표 일치 |
| 2 | 역무실의 "나"가 CCTV에 보임 (지금 역무실에 없는데) | 보이지 않음 |
| 3 | 이미 출발한 열차가 다시 도착 | 출발 완료 |
| 4 | 관제센터 무전에서 "퇴근하세요"라고 하지만 시간이 안 됨 | 정상 교신 |
| 5 | 승객이 전부 같은 얼굴 | 다양한 얼굴 |

### 5.2 대응 시스템

```
이상현상 감지
    │
    ├── [무시] → 공포 게이지 상승, 이상현상 악화
    │
    ├── [역무 일지에 기록] → 정상화 시도 (Tier 1 해결)
    │
    ├── [관제센터 보고] → 정상화 진행 (Tier 2 해결)
    │
    └── [직접 대응 행동] → 즉각 해결 or 실패 (Tier 3)
          ├─ 올바른 대응 → 이상현상 소멸
          └─ 잘못된 대응 → 공포 게이지 대폭 상승
```

### 5.3 공포 게이지 (정신 오염도)

- 이상현상을 놓치거나 잘못 대응하면 **공포 게이지** 상승
- 게이지가 높아질수록:
  - 🔈 환청 발생 (존재하지 않는 방송, 발소리)
  - 👁️ 환각 발생 (가짜 이상현상 섞여서 판단 어려움)
  - 🌑 시야 점진적 어두워짐
  - ⚡ 손전등 깜빡임 증가
- **MAX 도달 시** → 배드엔딩 진입

## 6. 맵 구조 (탑승구 중심)

### 6.1 탑승구 구조도

```
                          [선로 A] ─── KTX 도착/출발
                            │
[역무실] ── [개찰구] ── [탑승 대합실] ── [플랫폼 A]
   │           │              │              │
 [창고]     [편의점]     [대기 벤치]    [안전 가드레일]
              │              │
          [화장실]     [지하통로] ── [플랫폼 B]
                          │              │
                     [계단/ESC]     [선로 B] ─── KTX 도착/출발
                          │
                     [비상구]
                          │
                     [??? 구역] ← 이상현상 심화 시 출현
```

### 6.2 주요 공간별 특징

| 공간 | 역할 | 이상현상 활용 |
|------|------|---------------|
| **역무실** | 거점. 방송·시간표·무전기 관리 | 안전 지대이지만 후반부에 침식됨 |
| **개찰구** | 탑승권 스캠·승객 진입 확인 | 탑승권 오류, 같은 승객 반복 통과 |
| **탑승 대합실** | 승객 대기 구역 | 승객 수 변화, 이상 행동, 대기석 위치 변경 |
| **플랫폼 A/B** | KTX 도착·출발 지점 | 미지의 열차, 행선지 변경, 승객이 없는데 출발하는 열차 |
| **지하통로** | 플랫폼 A↔B 이동 | 길이 변화, 무한 복도 현상 |
| **화장실** | 순찰 포인트 | 거울 이상, 잠긴 칸에서 소리 |
| **창고** | 장비·분실물 보관 | 없던 물건 등장, 물건 이동 |

## 8. 연출 및 분위기

### 8.1 사운드 디자인

| 요소 | 평상시 | 이상현상 시 |
|------|--------|-------------|
| **BGM** | 역 내 잔잔한 앰비언트 | 저주파 드론, 불협화음 레이어 추가 |
| **환경음** | 열차 소리, 안내방송, 환풍기 | 역재생, 음정 왜곡, 반복 |
| **효과음** | 발걸음, 문 열림 | 없는 곳에서 발소리, 무전 잡음 |

### 8.2 비주얼 연출

- **조명 전환**: 주간 자연광 + 형광등 → 석양 주황빛 → 야간 형광등만 남음 → 이상현상 시 깜빡임·색온도 변화
- **하늘/창밖**: 탑승구 창문 밖 하늘이 시간에 따라 변화 (맑음 → 노을 → 밤하늘 → 이상한 하늘)
- **포스트 프로세싱**: 공포 게이지에 따라 VHS 노이즈, 색수차, 비네팅 증가
- **카메라**: 미세한 화면 흔들림, 시야각(FOV) 변화로 불안감 조성
